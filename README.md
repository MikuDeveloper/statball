# STATBALL

Application for managing statesmanship of players football.

## Project Initialization

Follow the following steps to configure and run the project:

### 1. Installing Dependencies

```bash
flutter pub get
```

### 2. Generate Files with build_runner

```bash
dart run build_runner build
```

### 3. Environment Variables Configuration

Copy the `.env_template` file to the project root and rename it to `.env`:

```bash
cp .env_template .env
```

Then, edit the `.env` file and modify the values according to your local configuration.
